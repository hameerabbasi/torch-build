# Quick PyTorch Build Setup

Supported Platforms: Linux (amd64), macOS (arm64)

## 0. Install Pixi

```sh
curl -fsSL https://pixi.sh/install.sh | sh
```

OR

```sh
wget -qO- https://pixi.sh/install.sh | sh
```

## 1. Clone

```sh
pixi run clone
```

## 2. Build

```sh
pixi run build-core
```

## X. Update

```sh
pixi run update
```
